# Фронтенд

Ванильный HTML5 / CSS3 / JavaScript (ES-модули). Ни сборщика, ни
зависимостей, ни `node_modules`.

---

## Почему без фреймворка

Сборка — это точка отказа: версии плагинов, кеш сборщика, расхождение
`package-lock.json` между окружениями, отдельный шаг в пайплайне. Для
интерфейса, который делает пять экранов, эта сложность не окупается.

Что даёт нативный подход:

- правка видна после сохранения, без пересборки;
- аудит безопасности целиком в своём коде, без транзитивных зависимостей;
- нулевой бюджет: полная страница — десятки килобайт;
- `textContent` вместо `innerHTML` — XSS невозможен по построению.

Цена: нет виртуального DOM, нет реактивности, нет маршрутизации из коробки.
Всё это — `dom.js`, `store.js` и `router.js`, суммарно около 400 строк.

## Архитектура

### Однонаправленный поток

```
роутер → страница → services(api.js) → конверт {ok, data}
                       ↓
                    store → подписчики → перерисовка
```

Страница не знает про HTTP-детали, `api.js` не знает про домен, `store` не
знает про страницы. Подписка на изменение состояния возвращает функцию
отписки — утечки слушателей не бывает by construction.

### `api.js`

- прикрепляет CSRF-заголовок к небезопасным методам;
- разбирает конверт и превращает ошибку в `ApiError` с `code`;
- **обновляет токен один раз**: пять параллельных 401 ждут один refresh, а не
  запускают пять, каждый из которых отменил бы токен предыдущего;
- читает CSRF из cookie при каждом запросе, а не кэширует: сервер крутит
  токен при входе.

### `dom.js`

`el('div', {class: 'x', onclick: fn}, ...children)` — единственный способ
создать узел. Значения через `textContent`, атрибуты — через
`setAttribute`. URL проходят проверку схемы: `javascript:` и `data:text/html`
превращаются в `#`.

### `router.js`

Каждая страница возвращает `{node, unmount}`. `unmount` вызывается перед
переходом: очищаются таймеры, `IntersectionObserver`, слушатели сокетов.
Именно поэтому «работает, пока не зайдёшь на другую страницу» здесь не
воспроизводится.

### `realtime.js`

- переподключение с нарастающей задержкой;
- **очередь исходящих**: сообщение, написанное без связи, уходит при
  восстановлении;
- **номер приёма** отбрасывает дубликаты после переподключения;
- при переподключении история перечитывается: между разрывом и
  восстановлением могли прийти сообщения, которых сокет не видел.

## Безопасность на клиенте

| Мера | Где |
|---|---|
| Ни одного `innerHTML` для пользовательских данных | `dom.js` |
| CSP без `unsafe-inline` для скриптов | `nginx`, политика приложения |
| Токен в `HttpOnly`-cookie, не в `localStorage` | недоступен скриптам |
| Проверка схем URL | `el()`, `isSafeUrl` |
| `referrerpolicy` строгий | `index.html` |
| Никаких сторонних трекеров | ни одного внешнего скрипта, кроме шрифта и Socket.IO |

CI падает, если `innerHTML` появляется вне рендерера юридических документов:
контент там проходит серверную очистку **до** сохранения.

Единственные внешние ресурсы — шрифт Inter и клиент Socket.IO. Оба
подключаются с CDN; во внутреннем контуре это отключается в `index.html`.

## Адаптивность

| Ширина | Раскладка |
|---|---|
| ≥ 1024 | Три колонки: сайдбар · лента · правый рельс |
| 768–1023 | Две колонки, правый рельс скрыт |
| < 768 | Одна колонка, нижняя навигация, FAB |
| < 900 (auth) | Форма без рекламной половины |

Мобильная навигация учитывает `env(safe-area-inset-bottom)` — иначе
индикатор жестов перекрывает последний пункт.

`prefers-reduced-motion: reduce` обнуляет все переменные длительности.
Анимации здесь декоративны, поэтому их отключение ничего не ломает.

## Производительность

- Бесконечная прокрутка через `IntersectionObserver` с `rootMargin: 600px`:
  данные начинают грузиться до того, как пользователь доскроллил.
- `loading="lazy"` и `decoding="async"` на всех изображениях.
- Скелетоны вместо спиннеров: контент не прыгает при загрузке.
- Правый рельс грузится отложенно, через 400 мс — он не должен задерживать ленту.
- WebSocket-сообщения добавляются без перерисовки всего треда.

## Локальная разработка

Фронтенд раздаётся nginx, но подходит и любой статический сервер:

```bash
cd frontend && python -m http.server 8000
```

Проксирование `/api` на Flask при разработке — через `nginx/site.conf`
или `flask run` с `SITE_URL=http://localhost:8000`.

## Иконки

```bash
python tools/generate_icons.py
```

Скрипт растеризует те же кривые Безье, что и SVG-логотип, чистым Python
без зависимостей. Выход побайтово воспроизводим, поэтому повторный запуск не
создаёт лишний diff.

## Чего здесь нет

| Отсутствует | Почему |
|---|---|
| Сборка, бандлер | Нет шага сборки — нет точки отказа |
| Фреймворк | Пять экранов не требуют виртуального DOM |
| Сторонние библиотеки | Аудит целиком в своём коде |
| Тёмная тема | Токены готовы; палитра требует доработки контраста, а не автоматической инверсии |
| Сторис | Не входило в объём |
