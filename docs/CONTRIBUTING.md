## Как добавить эндпоинт

1. **Бизнес-логика** — в `app/services/`, без `request`. Сервис возвращает
   объекты или словари и сам коммитит транзакцию.
2. **Валидация** — `Schema` из `app/security/validators.py`. Все поля собирают
   ошибки за один проход, чтобы форма подсвечивала всё сразу.
3. **Маршрут** — в соответствующем `app/api/*.py`, с декоратором
   `@auth_required` / `@auth_optional` / `@moderator_required`.
4. **Ошибки** — только классами из `app/utils/responses.py`, всегда с `code`.
   Произвольная строка вместо `ApiError` станет 500.
5. **Документация** — путь в `spec/openapi.yaml`, затем `make openapi`.
6. **Тест** — включая границу авторизации, а не только успешный случай.

CSRF, глобальный rate limit, `request_id` и заголовки безопасности уже
действуют глобально: новый изменяющий маршрут защищён автоматически.

## Как добавить модель

1. Класс в `app/models/` с `PrimaryKeyMixin`, `PublicIdMixin`, `TimestampMixin`.
2. Для дат — `UTCDateTime`, а не `DateTime` (иначе вернётся неоднородность
   aware/naive между PostgreSQL и SQLite).
3. Индекс под **точный** запрос, а не «на всякий случай».
4. Импорт в `app/models/__init__.py` — иначе таблица не создастся.
5. `make migrate-new m="…"` и `make migrate`.
6. Инвалидация кэша в сервисе после записи.

## Правила, которые нельзя нарушать

| Правило | Почему |
|---|---|
| Пользовательский текст — только `textContent` | `innerHTML` по определению создаёт XSS |
| Никогда не пишите содержимое сообщений в логи | Логи покидают периметр дольше, чем база |
| Токены хранятся только как хеш | Утечка базы не должна давать рабочие ссылки |
| Счётчики пересчитывать, а не инкрементить | Иначе они разъезжаются навсегда |
| Не возвращать `internal id` | Перебор `id` раскрывает объём |
| Ошибка видимости — `404`, а не `403` | `403` подтверждает существование |
| `beat` — один экземпляр | Два планировщика = двойные письма и удаления |
| Новые эндпоинты отдают `Cache-Control: no-store` | Кэш ответов с данными пользователя |

## Имена событий в логах

Формат `domain.event` через `log_event()`. Имя стабильно: на нём строятся
алерты и дашборды.

```
auth.registered · auth.login · auth.login_failed · auth.account_locked
post.created · post.deleted · comment.created
moderation.report_created · moderation.blocked · moderation.auto_hidden
spam.signal · ratelimit.exceeded · csrf_mismatch
gdpr.export_completed · account.purged · maintenance.backup_stale
db.slow_query · celery.task_failed
```

## Фоновые задачи

| Задача | Период | Назначение |
|---|---|---|
| `maintenance.purge_expired_tokens` | 6 ч | Одноразовые токены старше 30 дней |
| `maintenance.purge_orphan_uploads` | 3 ч | Загрузки, к которым не привязан пост |
| `maintenance.execute_scheduled_deletions` | 2 ч | Аккаунты, у которых истёк льготный период |
| `maintenance.archive_stale_posts` | сутки | Политика хранения контента |
| `maintenance.warm_cache` | 30 мин | Прогрев ленты и хэштегов |
| `moderation.expire_actions` | 1 ч | Снятие истёкших ограничений |
| `moderation.sweep_recent` | 4 ч | Повторная проверка недавних публикаций |
| `moderation.rotate_spam_scores` | 1 ч | Затухание и очистка сигналов риска |
| `gdpr.purge_exports` | 6 ч | Удаление выгрузок после 7 дней |
| `maintenance.check_backups` | 6 ч | Сигнал, если бэкапа нет более 48 ч |

## Переменные, которые чаще всего настраивают

| Переменная | Смысл |
|---|---|
| `TRUSTED_PROXY_COUNT` | Число прокси. Слишком мало — цикл редиректов; слишком много — подмена IP |
| `MODERATION_FAIL_CLOSED` | `true` при сбое классификатора отправляет всё на ручную проверку |
| `BCRYPT_ROUNDS` | 12 ≈ 250 мс. Поднимайте вместе с мощностью CPU |
| `DATA_RETENTION_DAYS` | Срок хранения контента |
| `SOCKETIO_MESSAGE_QUEUE` | Обязателен при нескольких подах, иначе сообщения теряются |

## Чего система сознательно не делает

- **Нет 2FA.** Пароль — единственный фактор. Подключение внешнего IdP по OIDC
  закрывает это без изменений в коде.
- **Нет сквозного шифрования переписки.** Сервер видит сообщения.
- **Нет федерации (ActivityPub).** Закрытый периметр.
- **Поиск хэштегов без скользящего окна.** Популярное не выделяется.

Полный список с последствиями — в разделе «Известные ограничения»
[SECURITY.md](SECURITY.md).
